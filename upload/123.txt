=== PUBLIC/JS/MAP.JS ===
1. Init Leaflet map: L.map('map').setView([55.7558, 37.6173], 10).
2. Base layer: MapLibre Demo Tiles via MapLibre GL Leaflet:
   maplibreGL({ style: 'https://demotiles.maplibre.org/style.json' }).addTo(map);
3. Fetch /data/map-layers.json → { sensors, pesticides, honeyPlants }.
4. Pesticides layer: red polygons (L.polygon) from coordinates, popup (name, pesticide, date). Always visible.
5. Honey plants layer: green polygons, popup (name, plant). Always visible.
6. Precipitation layer (RainViewer):
   - Fetch https://api.rainviewer.com/public/weather-maps.json
   - Take last frame from radar.past, construct tile URL:
     https://tilecache.rainviewer.com + frame.path + /256/{z}/{x}/{y}/2/1_1.png
   - Add as L.tileLayer with opacity 0.6. If fetch fails, skip silently.
7. Apiary layer (activation-driven):
   - localStorage key: "activatedSensors" (JSON array of sensor codes).
   - Function loadActivated() → read localStorage, for each code look up in sensors array, add L.marker (green circleMarker) at sensor.lat/lon with popup "<b>{name}</b><br>Ульев: {hiveCount}<br>Датчик: {code}". Add to a single L.layerGroup apiaryLayer.
   - Function renderActivatedList() → populate <ul id="activated-list"> with items "<b>{code}</b> — {name} <button data-code='{code}'>Удалить</button>".
   - Activation flow:
     * On click #activate-btn: read #sensor-code value, trim, uppercase.
     * If empty → #activation-msg red "Введите код датчика".
     * Find sensor by code in sensors array.
     * If not found → #activation-msg red "❌ Код не найден".
     * If already in localStorage → #activation-msg yellow "⚠️ Датчик уже активирован".
     * Else → push code to localStorage array, add marker to apiaryLayer, update list, #activation-msg green "✅ Датчик {code} активирован: {name}". Clear input.
   - Deactivation flow:
     * On click on "Удалить" button in list (delegated event): remove code from localStorage, remove corresponding marker from apiaryLayer, remove list item, show #activation-msg gray "Датчик {code} деактивирован".
   - On page load: call loadActivated() and renderActivatedList().
   - Sensors that are NOT activated MUST NOT appear on the map.
8. L.control.layers with labels: "🐝 Пасеки", "⚠️ Пестициды", "🌸 Медоносные растения", "🌧 Осадки". Apiary layer added only when at least one sensor activated (or add empty layer, doesn't matter).
9. Plain JS, no frameworks, no bundler, no other dependencies.
